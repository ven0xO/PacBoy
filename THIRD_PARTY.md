## LearnOpenGL helper code

The following bundled files are based on code from
[LearnOpenGL](https://learnopengl.com/):

- `external/camera.h`, based on the
  [Camera chapter](https://learnopengl.com/Getting-started/Camera);
- `external/shader_s.h`, based on the
  [Shaders chapter](https://learnopengl.com/Getting-started/Shaders).

LearnOpenGL code samples: Copyright ©
[Joey de Vries](https://twitter.com/JoeyDeVriez). They are published under the
[Creative Commons Attribution-NonCommercial 4.0 International license](https://creativecommons.org/licenses/by-nc/4.0/),
as described on the official [LearnOpenGL About page](https://learnopengl.com/About).

The bundled copies have been adapted for PacBoy. Those modifications do not
change the upstream license, so the two files are not covered by PacBoy's MIT
license. The NonCommercial condition matters: replace the helpers with
original code or obtain separate permission before distributing PacBoy
commercially.

## GLAD

PacBoy bundles a loader generated by
[GLAD](https://github.com/Dav1dde/glad) 0.1.36 under `external/GLAD`.
GLAD's generated code is offered under Public Domain, WTFPL, or CC0 terms.
The generated `external/GLAD/include/KHR/khrplatform.h` retains its own
Khronos Group copyright and permission notice in the file.

## GLFW

[GLFW](https://github.com/glfw/glfw) is a system dependency used for window
creation, the OpenGL context, and input. GLFW is licensed under the
[zlib/libpng license](https://www.glfw.org/license.html).

## GLM

[GLM](https://github.com/g-truc/glm) is a system dependency used for vectors,
matrices, and transformations. GLM is available under the
[MIT license or the Happy Bunny License](https://github.com/g-truc/glm/blob/master/copying.txt).

## nlohmann/json

[JSON for Modern C++](https://github.com/nlohmann/json) 3.12.0 is downloaded
by CMake and used for the local scoreboard. It is licensed under the
[MIT License](https://github.com/nlohmann/json/blob/v3.12.0/LICENSE.MIT).
Refer to the upstream project for notices covering code bundled inside that
distribution.

## miniaudio

[miniaudio](https://github.com/mackron/miniaudio) 0.11.25 is downloaded by
CMake and used for sound playback. PacBoy uses it under the
[MIT No Attribution license](https://github.com/mackron/miniaudio/blob/0.11.25/LICENSE).

## Catch2

[Catch2](https://github.com/catchorg/Catch2) 3.15.0 is found locally or
downloaded when tests are enabled. It is licensed under the
[Boost Software License 1.0](https://github.com/catchorg/Catch2/blob/v3.15.0/LICENSE.txt).
